# react-colorful.com

Website for [react-colorful](https://github.com/omgovich/react-colorful), a tiny color picker component for React and Preact.

Built with Next.js, [react-colorful](https://github.com/omgovich/react-colorful) and [colord](https://github.com/omgovich/colord). The hero background is a WebGL mesh gradient whose palette comes from the picked color.

## Development

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Agent docs

`public/llms.txt`, `public/index.md` and `public/docs/api.md` are Markdown docs for LLMs and agents, following [colord.dev](https://colord.dev/llms.txt). `docs/api.md` is a cleaned snapshot of the react-colorful README; regenerate it when a new version ships.
